Marcos dicta sus mensajes con Wispr Flow. Los nombres del lore se transcriben mal con frecuencia.

**Why:** Marcos lo dijo explícitamente: *"Si pone Nireh, pues es el equivalente a Nireh tal y como la conocemos en nuestro libro. Tú utiliza los nombres que ya teníamos antes."* Preguntar cada vez rompe el flujo de trabajo iterativo.

**How to apply:**
- Mapear automáticamente al canon más cercano fonéticamente. Ejemplos vistos:
  - *Nireh / Nire* → [[canon/personajes/nyree|Nyree]]
  - *Mor* → [[canon/personajes/muoro|Muoro]]
  - *Zayn* → [[canon/personajes/theim|Theim]]
- Si el mapeo es ambiguo (dos personajes igual de cercanos), preguntar UNA vez para confirmar, no asumir.
- Aplica solo a transcripciones evidentes. Si Marcos introduce un nombre nuevo deliberadamente (personaje nuevo), no forzar mapeo: preguntar.
- Lista viva: [[canon/personajes/_personajes]] es la fuente de verdad para los nombres válidos.
