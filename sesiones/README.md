# Sesiones

Log cronológico de cada sesión de trabajo en *Eris*. Una entrada por sesión, archivo nombrado `AAAA-MM-DD-<slug>.md` (slug del foco principal del día).

## Qué va aquí

- Resumen de la sesión: qué se hizo.
- Decisiones puntuales tomadas (narrativas, canónicas, de estructura).
- Capítulos escritos o reescritos, con link a su archivo.
- Archivos canon creados / modificados, con link.
- Pendiente para la siguiente sesión.

## Qué NO va aquí

- **Reglas atemporales de estilo / proceso / preferencias**: esas viven en `memory/` (carpeta espejo del sistema de auto-memoria) como `feedback_*.md`. Si en una sesión surge una regla nueva, **crearla en `memory/`** y **referenciarla desde el log** con un link — no duplicar contenido.
- Canon nuevo (personajes, lugares, sistemas): va en `canon/`. Aquí se referencia.

## Diferencia con `[[ESTADO]]`

- `[[ESTADO]]` es **el estado vivo del proyecto** (puerta de entrada de cada sesión): qué está validado, qué está pendiente, próximos pasos. Se reescribe / actualiza cada sesión.
- `sesiones/` es **el archivo histórico** inmutable de cada día. Una vez cerrada una sesión, ese archivo no se toca.

## Cómo cerrar una sesión

1. Copiar `_plantilla.md` a `AAAA-MM-DD-<slug>.md`.
2. Rellenar las secciones.
3. Actualizar `[[ESTADO]]` reflejando los pendientes que quedan vivos.
4. Si surgió alguna regla nueva, crearla en `memory/` y enlazarla.
